# F-012: Guard bundle size, privacy and fonts in CI

- **Milestone:** M3 · **Size:** S · **Requirements:** R-011, R-012, R-013 · **Depends on:** F-007
- **Screens:** none (CI guards)
- **Branch:** `factory/F-012-ci-guards`, stacked on `factory/F-011-load-error` (PR #12)

## Acceptance criteria

1. Given a production build, when the size check runs, then the gzipped sum of `dist/**/*.js` is under 51,200 bytes; otherwise the check exits non-zero and fails CI.
2. Given a full game in Playwright, when it ends, then:
   - every request went to the page's own origin
   - no font files were requested
   - `document.cookie` is empty
   - `localStorage` and `sessionStorage` are empty
3. Given `dist/`, when it is scanned, then no `script`, `link` or `iframe` points to another origin; otherwise the check exits non-zero.

## Modules

- **`scripts/check-bundle-size.mjs`:**
  - Exports `measureGzippedJavaScript(directory)`, which returns `{ files: [{ path, gzippedBytes }], totalBytes }`, using Node's `zlib.gzipSync` at level 9.
  - As a CLI, `node scripts/check-bundle-size.mjs [dist] [--limit 51200]` prints each file and the total, and exits 1 when the total ≥ limit, or when no JS files are found (an empty build must not pass).
- **`scripts/check-build-origins.mjs`** (named with whole words; the lint naming rule rejects the abbreviation "dist" in file names):
  - Exports `findExternalReferences(directory)`, which scans `*.html` for `<script src>`, `<link href>` and `<iframe src>`, and `*.css`/`*.js` for `url(...)` and `import(...)`/`from "..."` specifiers. It reports any absolute `http(s)://`, protocol-relative `//` or `data:` script origin that is not the page itself.
  - Relative URLs (`./assets/...`) and fragment-only references are allowed.
  - As a CLI, it exits 1 on any finding and prints each one.
- **`package.json`:** `check:size` and `check:origins` scripts.
- **`.github/workflows/ci.yml`:** the `checks` job runs both after `npm run build`.
- **`tsconfig.json`:** includes `scripts`, so they are typed-linted like everything else.

## Tests to write first

- **`tests/unit/check-bundle-size.test.ts`**, with fixture directories created in a temp dir:
  - a small JS file passes with its total reported
  - a random, incompressible file over the limit fails through the CLI (exit 1)
  - an empty directory fails
  - the real `dist/`, if present, passes (skipped when `dist/` hasn't been built)
- **`tests/unit/check-build-origins.test.ts`**, with fixtures:
  - relative assets pass
  - `<script src="https://cdn.example.com/x.js">`, `<link href="//fonts.example.com/f.css">` and `<iframe src="https://example.com">` are each reported
  - the CLI exits 1 on a finding and 0 on a clean directory
- **`tests/e2e/privacy.spec.ts`** (all 5 projects):
  - a full keyboard- or pointer-driven game (the 3b draw) while recording every request (`page.on("request")`)
  - every request URL's origin equals the page's origin
  - no request has resource type `font` or a font extension
  - after the game, `document.cookie === ""`, `localStorage.length === 0` and `sessionStorage.length === 0`

## Approach

Plain Node scripts with no dependencies, kept testable through exported functions. CI runs the same CLIs a developer runs locally.

- **Given** the game state module, **when** a human move is submitted while it is the computer's turn or after the game has ended, **then** the move is rejected and the returned state equals the input state (unit test).

+/** @typedef {{ file: string; kind: string; url: string }} ExternalReference */

+const HTML_PATTERNS = [
+  { kind: "script", pattern: /<script\b[^>]*\ssrc\s*=\s*["']([^"']+)["']/gi },
+  { kind: "link", pattern: /<link\b[^>]*\shref\s*=\s*["']([^"']+)["']/gi },
+  { kind: "iframe", pattern: /<iframe\b[^>]*\ssrc\s*=\s*["']([^"']+)["']/gi },

+const CSS_URL_PATTERN = /url\(\s*["']?([^"')\s]+)["']?\s*\)/gi;
+const JAVASCRIPT_IMPORT_PATTERN =
+  /(?:\bfrom\s*|\bimport\s*\(\s*)["']([^"']+)["']/g;
+const OTHER_ORIGIN_PATTERN = /^(?:[a-z][a-z0-9+.-]*:)?\/\//i;

+/**
+ * @param {string} directory
+ * @returns {string[]}
+ */
+function listFilesRecursively(directory) {
+  return readdirSync(directory, { withFileTypes: true }).flatMap((entry) => {
+    const entryPath = path.join(directory, entry.name);
+    return entry.isDirectory() ? listFilesRecursively(entryPath) : [entryPath];
+  });
+}

+/**
+ * @param {string} url
+ * @param {string} kind
+ * @returns {boolean}
+ */
+function isExternal(url, kind) {
+  if (OTHER_ORIGIN_PATTERN.test(url)) {
+    return true;
+  }
+  // An inline data: script runs code that did not come from the site's files.
+  return kind === "script" && url.toLowerCase().startsWith("data:");
+}

+ * @returns {string[]}

+  return [...text.matchAll(pattern)].flatMap((match) =>
+    match[1] === undefined ? [] : [match[1]],
+  );

+/**
+ * Gzip size (level 9) of every .js file under `directory`, and their total.
+ * @param {string} directory
+ * @returns {{ files: { path: string; gzippedBytes: number }[]; totalBytes: number }}

+      gzippedBytes: gzipSync(readFileSync(filePath), { level: 9 }).length,
+    }));

+      (argument, index) => !argument.startsWith("--") && !isLimitValue(index),
+    ) ?? "dist";

+    measurement = measureGzippedJavaScript(directory);
