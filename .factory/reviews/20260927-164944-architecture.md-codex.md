## Verdict
AGREE-WITH-CONCERNS — The focus rule and board-bounding-box criterion are consistent and testable, but the proposed load-error handler will not survive a standard Vite production build.

## Findings
- [C1] [HIGH] §2, Page / R-001 — Vite removes the source module script tag and generates a replacement without preserving `onerror` — its [HTML build implementation](https://github.com/vitejs/vite/blob/main/packages/vite/src/node/plugins/html.ts) explicitly removes the original tag and constructs one with `type`, `crossorigin`, `src` and optional `async`; aborting the production bundle therefore leaves the fallback hidden, and `main.ts` cannot help because it never executes — inject the handler into the generated tag through a post-build HTML transform, or install an independent inline error listener before module loading; verify the blocked-request case against the built `dist/`.

## Missing
