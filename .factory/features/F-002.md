# F-002: Model the board: marks, lines, winner and draw detection

- **Milestone:** M2 · **Size:** S · **Requirements:** R-001, R-004 · **Depends on:** F-001
- **Screens:** none (pure game core, ADR-009)
- **Branch:** `factory/F-002-board-model`, stacked on `factory/F-001-followup-ci-and-naming` (PR #2)

## Acceptance criteria

1. Given each of the 8 lines filled with X, and separately with O, when the board is evaluated, then the winner is that symbol and the line is identified (16 cases).
2. Given a full board with no three in a row, when it is evaluated, then the result is a draw; given a non-full board with no line, then there is no result.
3. Given a board and an occupied index, when `placeMark` is called, then it throws (documented) and never mutates the input; given an empty index, it returns a new board with only that square changed.
4. `emptySquares` returns indexes in reading order.

## Tests to write first (`tests/unit/board.test.ts`)

- `LINES` has exactly 8 lines: 3 rows, 3 columns, 2 diagonals, in that order, with indexes 0–8 row-major.
- 16 win cases: each line filled with X, then with O, amid otherwise mixed and non-winning squares where possible. `findWinner` returns `{ winner, line }` with the exact line, and `evaluateResult` returns `{ kind: "win", winner, line }`.
- Draw: a full board with no line gives `evaluateResult` → `{ kind: "draw" }` and `isFull` → true. A partial board with no line gives `evaluateResult` → `null`, `isFull` → false, and `findWinner` → `null`.
- `placeMark` on an empty index returns a new board: the input is unchanged (deep-equal to a copy taken before the call), only that index differs, and the input is not the same reference.
- `placeMark` on an occupied index throws a `RangeError` naming the square, and the input is unchanged. An index outside 0–8 or not an integer also throws a `RangeError`.
- `emptySquares` returns ascending indexes of empty cells: all 9 for the empty board, none for a full board.
- `createEmptyBoard` returns 9 `null` cells.

## Files expected

`src/game/board.ts`, `tests/unit/board.test.ts`.

## Approach

Pure, DOM-free module (architecture §2–3, ADR-009):
- **Types:** `Mark = "X" | "O"`, `Cell = Mark | null`, `Board = readonly Cell[]` (length 9, index = (row − 1) × 3 + (column − 1)), `Line = readonly [number, number, number]`, and `BoardResult = { kind: "win"; winner: Mark; line: Line } | { kind: "draw" }`.
- **`LINES`:** a frozen constant.
- **Functions:** `createEmptyBoard`, `findWinner`, `isFull`, `evaluateResult`, `emptySquares`, and `placeMark(board, index, mark)`.
- **Invalid moves throw:** `placeMark` throws `RangeError` for an occupied or invalid index. Callers (the F-004 state machine) check legality first and turn illegal input into `rejected` events; a throw here means a programming error, not user input.
- No memoization or search here; that is F-003.
