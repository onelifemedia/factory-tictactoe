Mockup: 1. Choose who goes first

The first state on load and after “Play again”. Traces to R-001, R-002, R-006, R-007, R-010, R-012 and R-013. The board is shown empty and disabled so a newcomer sees what the game is. The choice sits below the board in the action area, which keeps its height in every state so the board never moves.

1a. Default (fresh load or after Play again)

Focus is on “You go first” after Play again. On a fresh load nothing is focused until the player tabs; Tab skips the disabled board and reaches “You go first”. Both choices look the same because neither is preferred. They stack when they don't fit side by side.

Phone, 320 px wide

Tic-tac-toe

Who goes first?

Screen reader hears (live region, not visible):Nothing on a fresh load. After “Play again”, focus moving to “You go first” reads its name. A1/A2 are spoken when a game starts.

1b. Error: the game didn't load (JavaScript on, bundle failed)

This message is in index.html with the hidden attribute. It is revealed only by a small inline capture-phase error listener when the script fails to load (or by main.ts if it throws while starting; architecture §2), so it never flashes during a normal load, and never appears next to the no-JavaScript message.
