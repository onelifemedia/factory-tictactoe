3a. Computer wins with a diagonal, winning line highlighted

You played row 1, column 1, then row 1, column 2, then row 2, column 1. The computer played row 2, column 2, then row 1, column 3, then won at row 3, column 1. The three winning squares get a 4px border, a continuous strike line and a pale fill, and the line is named in text, so colour isn't the only cue. Each mark has a patch of fill behind it so the O stays readable over the strike.
